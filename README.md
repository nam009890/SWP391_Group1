# EVMS

English Vocabulary Management System

## Tech Stack

Backend:

- Java 17
- Spring Boot
- Maven

Frontend:

- React
- Vite
- JavaScript

## Project Structure

backend/
frontend/

## Requirements

- JDK 17 or newer JDK capable of compiling target Java 17
- Node.js
- npm

## Run Backend

Windows:

```powershell
cd backend
.\mvnw spring-boot:run
```

## Run Frontend

```powershell
cd frontend
npm install
npm run dev
```
